# Cherry Trace — frontend

Internal ops cabinet for the General Cherry hackathon case (traceability + field feedback).

## Run

```bash
cd frontend
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Roles (demo login)

- **Адмін** — full cabinet
- **Інженер R&D** — feedback / quality focus
- **Збиральник** — assembly tracking focus

Auth is sessionStorage mock only.

## Brand

CSS tokens mirror `papka_color/general-cherry-brandbook.html` (not bundled from that folder). Visual tone aligned with [gencherry.com](https://gencherry.com/).

## Map disclaimer

Tracking markers near Lviv / Lutsk / Chernihiv are **fictional demo zones**, not real factory locations.
